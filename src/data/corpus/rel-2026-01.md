# Release notes — January 2026 (platform v2026.01)

Rolled out to all regions by 2026-01-15. API changes ship under version header `Meridian-Version: 2026-01-10` unless noted.

## New

- **UPI intent on desktop via QR handoff.** Checkout v3.2 renders a dynamic QR when `upi.flow: "intent"` is requested on desktop, closing the gap where intent silently fell back to collect. Merchants in the beta saw UPI success on desktop rise from 71% to 84%.
- **Scoped API keys.** Keys can now carry granular scopes (`payments:read`, `refunds:write`, `settlements:read`). Available under Developers → API Keys; unscoped keys continue to work (see deprecations).
- **Settlement holiday API.** `GET /v1/settlements/holidays?year=2026` returns the RBI holiday calendar as structured JSON.

## Improved

- Webhook dispatcher rebuilt on a partitioned queue; p95 delivery latency down from 4.1 s to 0.9 s at peak.
- `POST /v1/upi/validate_vpa` latency reduced ~35% via NPCI connection pooling.
- Dashboard settlement reports now include a `carried_forward` column for rows re-queued from rejected batches.

## Feature flags

- `checkout_qr_handoff` — default **on**; opt out until 2026-03-01 via Dashboard → Labs.
- `scoped_keys_enforcement` — default off; turning it on rejects unscoped keys account-wide (dry-run mode logs would-be rejections).

## Deprecations

- Unscoped legacy API keys: deprecated now, **end of life 2026-12-31**.
- Checkout v2 (iframe-only) enters maintenance mode; no new features, security fixes only, sunset announced for 2027-Q1.
