# Release notes — May 2026 (platform v2026.05)

Completed rollout 2026-05-22. API changes ship under `Meridian-Version: 2026-05-15`.

## New

- **International cards self-serve.** Enable international acceptance from Settings → Payment Methods with an inline compliance checklist; median activation time drops from 6 business days to 2. Amex still requires the manual addendum.
- **Reports API v2.** `POST /v1/reports` now supports scheduled recurring reports (daily/weekly/monthly) delivered to S3 or SFTP with PGP encryption. New report types: `dispute_aging`, `mandate_health`, `fira_summary`.
- **Risk Insights dashboard (beta).** Per-merchant view of decline reasons, issuer-level success rates, and a week-over-week anomaly feed. Join the beta under Dashboard → Labs → `risk_insights`.

## Improved

- Payout engine: settlement Batch A compute time cut 40% by parallelising fee calculation; cut-off adherence at 99.7% over the last 60 days.
- `GET /v1/payments` list endpoint now supports `settlement_id` and `utr` filters — the two most requested recon parameters.
- Hindi-language checkout strings revised for UPI AutoPay consent screens after merchant feedback.

## Feature flags

- `reports_v2_scheduling` — default on.
- `risk_insights_beta` — opt-in.
- `intl_selfserve_onboarding` — default on; flip off to retain the assisted flow.

## Deprecations and notices

- Reports API v1 (`GET /v1/reports/legacy`) is deprecated; end of life **2026-11-30**.
- Reminder: unscoped API keys stop working 2026-12-31. Dashboard now shows a per-key usage banner counting down.
